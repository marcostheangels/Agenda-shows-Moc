🚀 Publicação automática no GitHub

Cada Salvar pode atualizar o site para todos automaticamente. O token fica salvo só no seu navegador.

Gere em: github.com/settings/tokens → Fine-grained, marque "Contents: Read and write".

💾 Sem token configurado. Dados salvos apenas neste navegador.

📋 Como gerar o token passo a passo
  1. Acesse github.com/settings/tokens (Fine-grained token)
  2. Clique em Generate new token
  3. Em Repository access, selecione "Only select repositories" e escolha Agenda-shows-Moc
  4. Em Permissions → Repository permissions → Contents, marque Read and write
  5. Clique em Generate token e copie o token (começa com github_pat_)
  6. Cole no campo acima, clique em 🔍 Testar para confirmar, depois marque "Auto-publicar"
  7. Pronto! Agora todo Salvar atualiza o site em ~1 minuto
